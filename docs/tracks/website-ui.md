# Track 1: Website / UI

Design and build new features for the RideScore DC interface: everything a user actually touches and sees.

Teams work with a ready-to-go HTML/Docker environment built on the MapLibre frontend and PostGIS/Martin tile backend, so you can plug in and start building rather than setting up infrastructure from scratch.

## Open problems

- Let users submit or input their own street safety scores or observations
- Add ways for riders to flag hazards or leave feedback on a segment
- Improve mobile responsiveness
- Rethink how the map communicates safety information at a glance

## Before you come

Clone the website repo and follow the Front-End (lighter) or Full Stack (needs Docker) developer guide. Windows users: start with the WSL tab.
